# EX3 – Android Fragments App

##  Project Description

EX3 is an Android application developed using **Kotlin** in **Android Studio**. The project demonstrates the use of **Android Fragments** and navigation between different UI sections.

The application uses AndroidX libraries and is designed as part of a **Mobile Application Development (MAD)** practical assignment.

##  Aim

To develop an Android application using **Kotlin** that demonstrates the implementation and usage of **Fragments**.

##  Technologies Used

- **Language:** Kotlin
- **IDE:** Android Studio
- **UI:** XML / Jetpack Compose
- **Architecture Component:** Android Fragments
- **Material Design:** Material 3
- **Build System:** Gradle Kotlin DSL
- **Minimum SDK:** Android 7.0 (API 24)
- **Compile SDK:** Android API 37

##  Features

- Fragment-based Android application
- Multiple UI sections using Fragments
- Activity–Fragment integration
- AndroidX Fragment support
- Material Design components
- Responsive Android UI
- Runs on Android Emulator or physical Android devices
